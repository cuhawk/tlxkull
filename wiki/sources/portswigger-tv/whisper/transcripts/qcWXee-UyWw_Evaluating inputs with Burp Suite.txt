First of all, we'll look at manually evaluating individual inputs.
To do this, send a request to BurpRepeater.
Go to the Repeater tab, and modify each input in turn.
You might want to remove the input completely, give the input an empty value,
or maybe insert a collaborator payload in the input by highlighting it,
and using right-click and selecting Insert collaborator payload.
Once you've made your changes, click Send.
Review the responses for any interesting behaviour, such as input reflections or differences in response times.
To identify subtle changes between responses, you can send the responses to BurpComparer.
In BurpComparer, you can select the two responses, click Words or Bytes to compare them,
and a new window will open with the results.
Compare our highlights any differences between the two responses.
Next, if you're using BurpSuite Professional, you can scan inputs to identify potential vulnerabilities,
which BurpScanner flags as issues.
To scan a single input, highlight the input.
You can do this from any message editor in Burp, for example from proxy HTTP history.
Right-click and select Scan Selected Insertion Point.
In the Scan Launcher window, click OK to start the scan using the default configuration.
If you'd like to scan multiple inputs at the same time, send the request to BurpIntruder.
On the Intruder Positions tab, add a payload position for each input you want to scan.
You do this by selecting the input and clicking Add.
Right-click the request and select Scan Defined Insertion Points.
Again, when the Scan Launcher opens, click OK to start the scan using the default configuration.
BurpScanner will audit the request using only the selected inputs.
To view any issues identified by these scans, go to the Tasks panel on the dashboard,
click View Details beside the task to open the Task Details dialog,
and switch to the Issue Activity tab.
This will contain a record of all the issues found during the scan.
Finally, we'll look at Fuzzing Input to identify potential vulnerabilities.

If you're using BurpSuite Professional, open the Add from List drop-down menu,
and select one of the built-in fuzzing lists.
For example, Fuzzing Full, or in this case, Fuzzing SQL Injection.
Alternatively, you can add your own list.
