Hi. In this video, we'll look at using burp to test for blind SSRF. Blind server-side request
forgery, or SSRF, is a vulnerability that allows an attacker to induce an application to send HTTP
requests to a specified URL, but no response is returned to them. To detect blind SSRF vulnerabilities
with out-of-band testing, you can use burp collaborator to inject a domain into a request that attempts
to trigger an out-of-band interaction. Burp then monitors the collaborator server for any out-of-band
interactions using that domain. If burp collaborator detects that your application sent a request
to the inserted domain, that means it's vulnerable to SSRF. If you'd like to follow along, you
can use the Blind SSRF with Out-of-Band Detection Lab from our Web Security Academy. Once the
lab has launched, we need to identify a request into which we can insert a collaborator payload.
For this lab, we can visit one of the product pages. We need to send one of these requests
to Burp Repeater. I have one here in the proxy HTTP history tab. Switch to the Repeater tab.
We now need to insert our collaborator payload. For this demo, we'll replace the referrer header
with the collaborator payload. Click Send. Now go to the collaborator tab. You may need to click on
Poll Now to get the most recent interactions. Any interactions initiated by the target application
to the collaborator server for this payload will be listed in the table.
