You can use the links on the accompanying tutorial page to download the latest version
of Burpsuite Professional or Community Edition.
The software is also available from your account page on our website.
When you've downloaded the software, run the installer.
You'll be presented with an installation wizard.
Click Next through the options, and then Finish.
Finally launch Burpsuite.
When asked to select a project file and configuration, just click Next, and then Start Burp to skip
this for now.
If you're using Burpsuite Professional, enter your license key when prompted.
If you don't already have one, you can subscribe or request a free trial.
If you're completely new to Burpsuite, follow the rest of this tutorial for an interactive
guided tour of the core features.
The Learn tab contains links to useful tutorials and other resources to help you get started
with Burpsuite, discover new features, and take your skills to the next level.
