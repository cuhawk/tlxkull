Hi. Today we're going to look at testing for XXE injection vulnerabilities with Burp Suite.
XML External Entity Injection, also known as XXE, is a web security vulnerability that allows an
attacker to interfere with an application's processing of XML data. It occurs when user
input that contains a reference to a defined external entity is processed in an unsafe way
on the server side, so the application may return the value of the defined external entity within its responses.
