Once you've added a site to Burpsuite Enterprise Edition, if you need to make any site configuration
changes, you can edit existing sites.
First navigate to the sites page, select the site in question, select the details tab,
then click edit.
You can now make changes to the site configuration.
These are the same options as those available when adding a new site.
Once you've made the required changes, you can click save.
Thank you.
