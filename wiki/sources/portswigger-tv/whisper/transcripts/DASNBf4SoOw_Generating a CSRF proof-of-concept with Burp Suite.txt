Hi, in this video we're going to look at generating a CSERF proof of concept with Burp Suite.
Cross-site request forgery, or CSERF attacks, force a victim user to perform unintended actions on a website.
If a website is vulnerable to CSERF, an attacker can bypass the same origin policy,
which usually prevents websites from interfering with each other, meaning the attacker can create a web page that causes the victim user's browser to submit a request directly to the vulnerable website.
You can use Burp Suite Professional to automatically generate HTML for a proof of concept CSERF attack.
This is quicker and easier than manually creating the HTML, which can be cumbersome when the request contains a larger number of parameters.
You can follow along using the lab CSERF Vulnerability with No Defenses in our Web Security Academy.

You can use Burp Scanner to identify requests that are potentially vulnerable.
