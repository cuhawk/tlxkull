In this video we shall review how to download logs for your BurpSuite Enterprise Edition scans.
First select the Scans tab and select the scan in question. We can then navigate to the logging
tab which will display the event log and the scan debug log. To download the scan event log we can
select download event log. This log can be useful for debugging scans and can be provided to PortsWigger
support to assist in any issues you are experiencing with your scans. The same applies to the scan debug log.
We can select download and this log is typically used when required for support debugging. Thank you.
