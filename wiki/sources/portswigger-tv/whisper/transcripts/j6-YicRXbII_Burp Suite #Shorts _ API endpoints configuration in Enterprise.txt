Did you know in Burp Suite Enterprise you can now configure endpoints after uploading an API definition file and here's how.
When you create an API site and upload an API definition file, an endpoint tab will now appear.
You can select and deselect which endpoints will be scanned.
The filters and search can also be used to help you make your selection.
For example, if you want to exclude scanning delete methods on endpoints,
you can use the method filter to narrow down your view to only the delete methods and then deselect them all.
Once you're done with your selection, you can save the site and start a scan.
