the difference between crawled locations and audited items. And this is because a question

Well, what it comes down to is the fact that when the crawl is running, we are crawling the web
application like a user and we treat distinct web pages as locations. Whereas when the audit is
running, we are auditing HTTP messages. So there's a bit of a difference between a HTTP message and a
web page, which I'll go over now. To do this, I'm going to use the new crawl paths view, which came

between crawled locations and ordered items comes in. When we submitted the form add to cart, we got to a
