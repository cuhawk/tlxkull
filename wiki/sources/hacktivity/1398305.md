## AI Summary

Two XSS sanitization bypasses were discovered in GitLab. The SyntaxHighlightFilter creates HTML from unsanitized data, allowing for a server-side XSS filter bypass. Additionally, the gl-emoji custom element can be used to bypass the GitLab UI v-safe-html directive sanitization on the frontend side by injecting the payload into the name attribute. An attacker who can comment on an issue or other pages where comments can be posted can exploit these vulnerabilities to XSS users who visit that issue or page.
