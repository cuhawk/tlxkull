## AI Summary

The CCC CTF website was vulnerable to XXE (XML External Entity) injection, which allowed an attacker to read arbitrary files on the server. The vulnerability was exploited by creating a malicious XML file on a public S3 bucket, which contained a payload to exfiltrate sensitive files. The website was also vulnerable to SQL injection, which allowed an attacker to extract the admin password character by character through ICMP packets. The admin password was then used to log in to the admin dashboard of the Pinger service, where the flag was obtained.
