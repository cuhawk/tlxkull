## AI Summary

A SQL injection vulnerability was found in the `/include/findusers.php` script of ImpressCMS version 1.4.2. Unsanitized user input passed through the "groups" POST parameter was used to construct a SQL query without proper validation, allowing remote attackers to read sensitive data from the "users" database table through boolean-based SQL Injection attacks. This could potentially lead to full account takeovers.
