## AI Summary

A vulnerability was discovered in Evernote Android that allowed for remote code execution with just two clicks. The vulnerability was due to a path traversal weakness that allowed for the renaming of attachments with special characters, resulting in the downloaded attachment being saved in an unintended directory. The app did not sanitize the received filename, allowing for remote code execution when the attachment was clicked.
