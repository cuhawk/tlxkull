The yelp.com website was found to be vulnerable to a cross-site scripting (XSS) attack. The vulnerability was caused by the website's improper handling of the "guvo" cookie, which was reflected in the HTML response without proper sanitization. Additionally, a feature on the website that allowed setting the "yelpmainpaastacanary" cookie through a query parameter was abused to smuggle the malicious "guvo" cookie. This chained vulnerability resulted in a persistent XSS in the victim's browser.
