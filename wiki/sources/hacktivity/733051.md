A reflected cross-site scripting vulnerability was discovered in the URL parameter of the "Choose a data source" page at "https://bi.owox.com/ui/settings/connected-services/setup/". When a malicious URL containing script code was entered, it was reflected back without sanitization, allowing the script to execute in a victim's browser and potentially carry out actions like hijacking sessions.
