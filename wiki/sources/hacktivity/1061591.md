## AI Summary

A vulnerability existed in all versions of Nextcloud (18-20) that allowed users to act as a different user via DB-stored credentials. The issue was related to LDAP authentication and external SMB shares via DB stored credentials. The problem was that there was no check if the current user in the session was the same as the user for whom the credentials were stored. As a result, the stored credentials in the database were incorrect, and users could act as the admin user, accessing SMB shares on the network with higher privileges than themselves. The vulnerability was patched with a security conform bugfix.
