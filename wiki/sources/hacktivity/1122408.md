## AI Summary

A vulnerability in GitLab's GraphQL API allowed an attacker to bypass the existing CSRF protection by sending a GET request without the expected X-CSRF-Token header. This allowed the attacker to execute mutations, such as creating or editing queries, through the GET request. The impact of this vulnerability was that the attacker could control the GraphQL endpoint and potentially access sensitive information.
