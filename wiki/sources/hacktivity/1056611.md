## AI Summary

A vulnerability in Cisco Adaptive Security Appliance (ASA) Software and Cisco Firepower Threat Defense (FTD) Software allowed an unauthenticated attacker to conduct directory traversal attacks and obtain read and delete access to sensitive files on a targeted system. The vulnerability was due to a lack of proper input validation of the HTTP URL. An attacker could exploit this vulnerability by sending a crafted HTTP request containing directory traversal character sequences. The impact of the exploit could allow the attacker to view or delete arbitrary files on the system.
