## AI Summary

Server-side validation checks were implemented after access to SaaS apps protected via ZT's Access could be gained when a user account was deleted or disabled by preserving metadata of the Access JWT and using another active user account within the same organization, despite lacking proper privilege. The vulnerability was resolved by Cloudflare Engineering through necessary validation on the server side.
