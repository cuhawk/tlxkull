## AI Summary

A vulnerability was discovered where anonymous users could view the titles of private reports with pending email invitations for collaboration. This was possible by sending a GraphQL request or running JavaScript code while logged out. It only worked for anonymous users when the collaboration invitation was through the Manage Collaborators panel. This allowed anonymous users to read the titles of possibly unfixed private reports, which could be leveraged against the program depending on the specificity of the report titles.
