## AI Summary

A path traversal vulnerability was discovered in Apache HTTP Server versions 2.4.49 and 2.4.50. The fix for CVE-2021-41773 was found to be insufficient, allowing an attacker to map URLs to files outside the directories configured by Alias-like directives. This could lead to remote code execution if CGI scripts are enabled for these aliased paths. The vulnerability was fixed in version 2.4.51.
