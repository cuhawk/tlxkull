## AI Summary

The nginx.ingress.kubernetes.io/permanent-redirect annotation was not properly sanitized when passed into the nginx configuration, allowing code injection from users able to create ingress objects. This allowed commands to be run on the ingress-nginx-controller pod and the Kubernetes API to be accessed to retrieve secrets or config maps, posing a risk to cluster security and data. The vulnerability has since been addressed.
