## AI Summary

A Cross-Site Request Forgery (CSRF) vulnerability was discovered on several authenticated POST endpoints on a website. The vulnerability allowed an attacker to perform arbitrary actions on behalf of the user, as long as the user had a valid session cookie. The vulnerability was due to the lack of CSRF tokens and SameSite attribute for cookies. The impact of the vulnerability was that an attacker could modify the user's calendar, submit quizzes, request references, and send password reset emails.
