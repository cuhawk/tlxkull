## AI Summary

API tokens of Cloudflare users were vulnerable to unauthorized rotation by malicious actors who knew the victim's token ID due to lack of proper authorization checks. This could lead to DoS for the token owner and the applications that use it. The vulnerability was fixed by enforcing proper access controls for the Roll Token API method.
