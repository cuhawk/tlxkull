## AI Summary

The DotNetNuke (DNN) versions between 5.0.0 and 9.3.0 were affected by a deserialization vulnerability that could lead to remote code execution. The vulnerability was caused by the way DNN handled the `DNNPersonalization` cookie, which was used to store anonymous users' personalization options. The vulnerability was exploitable when the application was configured to handle 404 errors with its built-in error page.
