## AI Summary

A path traversal vulnerability was discovered in Concrete5 CMS version 8.5.4. An authenticated attacker with page editing rights could upload a PNG file containing PHP code and use its relative path in the `bFilename` parameter while editing layout design. This would lead to the execution of the injected malicious code. As a result, the attacker could run arbitrary system commands and obtain sensitive information.
