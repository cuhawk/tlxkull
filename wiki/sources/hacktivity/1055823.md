## AI Summary

A Server Side Request Forgery (SSRF) vulnerability was found in the Add a custom Integration feature on console.helium.com. An attacker could exploit this vulnerability to retrieve private meta-data from the AWS EC2 instance running on the server by creating a custom HTTP integration and setting the integration endpoint to http://169.254.169.254/latest/meta-data. The endpoint input is not validated, making the application vulnerable to the SSRF.
