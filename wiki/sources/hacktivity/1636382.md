## AI Summary

A vulnerability was discovered in the Synthetics Recorder tool, which allows attackers to inject arbitrary code into a recording session. The waitForNavigation event calls quote within the context of a multi-line comment, which can be escaped with a specially crafted URL. This can lead to code execution when the recorded session is saved and executed using the synthetic runner. Confidentiality and integrity impact are high, as an attacker with control over the website's content can run arbitrary code wherever the session is re-executed.
