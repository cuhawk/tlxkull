## AI Summary

A vulnerability was discovered in the Rust standard library's `std::fs::remove_dir_all()` function before version 1.58.1. The function is vulnerable to a time-of-check to time-of-use link replacement attack, which could allow an attacker with write access to a directory being deleted by a privileged process to trick the process into deleting sensitive files or directories. The vulnerability was caused by an incorrect implementation of the function's check for symbolic links, resulting in a race condition. The issue has been assigned CVE-2022-21658.
