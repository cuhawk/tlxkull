## AI Summary

Stored DOM XSS vulnerability was discovered in GitLab's Mermaid chart feature. The vulnerability was caused by a lack of sanitization of user-supplied values in the directives, which allowed an attacker to inject malicious code into the style tag via the `innerHTML` method. This could lead to the execution of arbitrary code in the context of the victim's browser. The vulnerability was reported to GitLab and has since been fixed.
