## AI Summary

A blind SSRF vulnerability was discovered on a web application that allowed attackers to make the server connect to internal-only services or arbitrary external systems, potentially leaking sensitive data or performing unauthorized actions. The vulnerability was found in the image upload URL downloader feature, which allowed attackers to upload a payload and observe HTTP and DNS interactions. The vulnerability was exploited by using a payload in the URL downloader and polling it in a Burp Collaborator client. The suggested mitigation was to create a whitelist of domains in DNS and to enable authentication on all services.
