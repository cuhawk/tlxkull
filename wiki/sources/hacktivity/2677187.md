CVE-2024-41937: Apache Airflow: Stored XSS Vulnerability on Provider Link

A stored cross-site scripting (XSS) vulnerability was discovered in Apache Airflow versions before 2.10.0. The vulnerability allowed the developer of a malicious provider to execute arbitrary script code when a user clicked on the provider documentation link. The issue was reported through the official Apache Airflow security email and was addressed in version 2.10.0.
