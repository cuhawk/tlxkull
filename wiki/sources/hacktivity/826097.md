## AI Summary

An SSRF vulnerability was found in the image API of PlayStation Network, which allowed attackers to fetch remote images over HTTP protocol using the `image` GET parameter and convert them to the desired format using the `format` GET parameter. This vulnerability could be chained to hit internal hosts leading to another SSRF, which allowed attackers to read internal images using the `file` protocol.
