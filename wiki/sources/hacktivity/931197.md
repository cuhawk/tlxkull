## AI Summary

A vulnerability was discovered in the `socket.io` module version 2.3.0 that allowed an attacker to bypass origin protection using special symbols, including "`" and "$". This could be exploited as a typical CSRF vulnerability, allowing an attacker to send and receive WebSocket messages on behalf of a user. The vulnerability was discovered on Linux arch 5.7.9-arch1-1, using Node v14.5.0 and NPM 6.14.6, and was found to affect Mozilla Firefox 79.0b8.
