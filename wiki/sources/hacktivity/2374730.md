The report identified a vulnerability in the Bykea application's booking detail and bids endpoints that could lead to the disclosure of sensitive information. The vulnerable endpoints allowed an attacker to access the booking details, bids information, and bids configuration of other users by modifying the `booking_id` parameter in the request URL. This issue was classified as an Insecure Direct Object Reference (IDOR) vulnerability.
