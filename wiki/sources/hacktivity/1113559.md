## AI Summary

A CSRF vulnerability was discovered in webapp.starbucks.co.jp that leaked an access token if an authenticated user opened a crafted HTML file in a browser other than Chrome. This could potentially allow an attacker to add a Starbucks card to the account and perform a single account takeover at login.starbucks.co.jp. The vulnerability has been resolved.
