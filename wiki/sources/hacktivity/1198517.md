## AI Summary

A stored XSS vulnerability was discovered in GitLab's custom emoji feature. The vulnerability was caused by insufficient escaping of the `src` value in the `emoji_image_tag` function. The vulnerability could be exploited by an attacker to execute arbitrary code in the context of a victim's browser. The vulnerability was fixed in GitLab version 13.12.0.
