## AI Summary

An improper authentication vulnerability was discovered on Snapchat's One Tap Password (OTP) login/logout flow. An attacker could log in to any account for which they had the user_id, which was exposed in several places and should not have been trusted in the request by the logout endpoint. This vulnerability allowed an attacker to log in as any user.
