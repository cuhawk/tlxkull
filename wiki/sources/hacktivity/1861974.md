## AI Summary

A path traversal vulnerability in the OAuth `redirect_uri` parameter allowed attackers to redirect authenticated users to their product page with their OAuth credentials, potentially leading to account takeover. This could occur due to the leakage of the user's authorization code via the query string in the redirect.
