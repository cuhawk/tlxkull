## AI Summary

A vulnerability was found that allowed unauthenticated remote attackers to conduct directory traversal attacks and read sensitive files on affected Cisco Adaptive Security Appliance and Cisco Firepower Threat Defense systems. This was due to a lack of proper input validation of URLs in HTTP requests. An attacker could exploit the vulnerability by sending a crafted HTTP request containing directory traversal character sequences. If successful, this would have allowed the attacker to view arbitrary files within the web services file system, including impersonating another VPN user. Cisco released software updates to address this issue.
