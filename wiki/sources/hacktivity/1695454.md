## AI Summary

An IDOR vulnerability was discovered in Pressable's API applications, allowing an attacker to view any API token and potentially take over the victim's account. By changing the application ID parameter in a POST request and removing all other parameters except the authenticity token, the attacker could access the victim's API credentials, including the client ID and client secret. The impact was critical as the attacker could access many things via the API, including the collaborator endpoint.
