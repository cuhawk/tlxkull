## AI Summary

A path traversal vulnerability was introduced in Node.js 20 due to insufficient patching of CVE-2023-30584. The vulnerability arises because the permission model implementation does not protect itself against the application overwriting built-in utility functions like path.resolve with user-defined implementations. This allows bypassing of path sanitization, enabling arbitrary file reads and writes. The vulnerability affects all Node.js 20.x users of the experimental permission model. It was reported by Tobias Nießen, who also provided the patch.
