## AI Summary

A path traversal vulnerability was discovered in the Nuget package registry of GitLab-EE. This allowed an attacker to create any file with an extension “.nupkg” in the filesystem, which could be used to read sensitive files in a GitLab instance. The vulnerability was caused by a path traversal issue in the metadata_extraction_service.rb file, which extracted the uploaded nupkg for the contained nuspec file. An attacker could upload a malicious nupkg file with a crafted XML file that contained a path traversal payload.
