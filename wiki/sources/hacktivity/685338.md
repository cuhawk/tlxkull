## AI Summary

The vulnerability discovered was an Insecure Direct Object Reference (IDOR) that allowed for mass account takeover without user interaction on the ███████ (https://███████.edu/) website. The vulnerability was found in the /chkUser.aspx endpoint, which was vulnerable to IDOR. The numeric user ID parameter could be altered to access other user accounts, allowing an attacker to change the email associated with the account. This could then be used to initiate a password reset and gain unauthorized access to the victim's account.
