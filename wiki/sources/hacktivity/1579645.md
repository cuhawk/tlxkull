## AI Summary

The `v-safe-html` directive in GitLab was not safe enough as it did not remove the `data-disable-with` attribute from HTML tags, which allowed an attacker to bypass sanitization and execute arbitrary code on the client-side. This vulnerability could be exploited via job error messages that contained user-provided CI job names. An attacker could use this vulnerability to perform arbitrary actions on behalf of victims.
