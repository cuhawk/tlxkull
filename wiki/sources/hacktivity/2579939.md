## AI Summary

The vulnerability allowed an attacker with direct network access to GitHub Enterprise Server to forge a SAML response and gain unauthorized access to the instance, including site administrator privileges, by exploiting a signature verification bypass. The vulnerability affected all versions of GitHub Enterprise Server prior to 3.14 and was addressed in versions 3.13.3, 3.12.8, 3.11.14, and 3.10.16.
