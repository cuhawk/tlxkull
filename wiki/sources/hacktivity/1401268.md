## AI Summary

Rocket.Chat versions 4.1.0 with the 'marked' parser were affected by a persistent CSS injection vulnerability. Due to more loose restrictions in the 'marked' parser, an attacker could inject malicious CSS code into messages, leading to the manipulation of the chat window's style, blocking of functionality, and hijacking of the content of targeted users. The vulnerability was fixed in version 5.0.
