## AI Summary

A possible code injection vulnerability was found in the Active Storage module of Rails, affecting versions >= 5.2.0 and impacting applications that use Active Storage with the image_processing processing in addition to the mini_magick back end for image_processing. The vulnerability could allow an attacker to achieve RCE by exploiting untrusted arbitrary input in the transformation method or its arguments. Fixed versions are available, and workarounds include implementing a strict allow-list on accepted transformation methods or arguments and a strict image magick security policy.
