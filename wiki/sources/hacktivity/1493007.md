## AI Summary

A vulnerability was found in a system where an unauthorized person could access the endpoint responsible for deleting user requests by providing just one parameter, leading to the deletion of legitimate user requests and causing data loss. The user request IDs were sequential numbers, making it possible for an attacker to delete all requests in the system. The suggested mitigation action was to perform a check if the user is logged in and authorized to use the endpoint.
