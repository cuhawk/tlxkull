## AI Summary

An arbitrary file read vulnerability was discovered during project import in GitLab. An attacker could exploit a mis-usage of json schema validator to read any file in the GitLab server, potentially leaking sensitive data such as credentials. The vulnerability also allowed for an SSRF attack. The issue affected GitLab.com and self-hosted GitLab instances.
