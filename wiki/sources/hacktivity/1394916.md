## AI Summary

A path traversal and file disclosure vulnerability was found in Apache HTTP Server 2.4.49. Attackers could use this vulnerability to map URLs to files outside the directories configured by Alias-like directives, potentially exposing sensitive data. This issue only affected Apache 2.4.49 and not earlier versions. The vulnerability was fixed in Apache HTTP Server 2.4.50.
