## AI Summary

The vulnerability allowed a guest user to escalate privileges to the admin group. The guest user first added themselves to the bot group, which had the "manage-own-integrations" permission. Using this, the user created a malicious integration script that added the user to the admin group. The vulnerability existed due to improper validation in the "insertOrUpdateUser" method, which did not properly check the user's permissions when modifying their groups.
