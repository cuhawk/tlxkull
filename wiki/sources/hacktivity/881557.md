A vulnerability in Slack's PDF viewer allowed for stored cross-site scripting (XSS) attacks. Attackers could upload a malicious PDF file containing special characters that could be executed as JavaScript code in the browser, potentially exposing user data. The issue was resolved by patching a vulnerable dependency in the PDF viewer. No customers were impacted by this vulnerability.
