## AI Summary

A vulnerability was discovered in the FogBugz import code used by GitLab that allowed for a full GET-based SSRF attack against gitlab.com. The vulnerability was caused by the use of `Kernel.Open` to download and store the result of an untrusted URL, which permitted URLs that resolve to or redirect to `127.0.0.1`. A vulnerability in a fogbugz.com subdomain that met certain criteria would have resulted in the SSRF issue against gitlab.com.
