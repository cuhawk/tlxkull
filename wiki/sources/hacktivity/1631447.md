## AI Summary

A stored XSS vulnerability was found in the login page of a website. The vulnerability was caused by the exposure of the "edit" GET parameter, which revealed a hidden markdown editor. An attacker could input and execute their own JavaScript code that would execute on everyone who accessed the login page every time. The vulnerability could also be used to upload images and deface the website. The only way to remove the XSS payload was to access the markdown editor and remove it.
