## AI Summary

A blind stored XSS vulnerability was found on a website's profile page, allowing an attacker to store malicious code in various fields. When an admin checks the profile, the code executes and sends sensitive information to the attacker, including the admin's IP address, backend application service, titles of mail chimp customers, internal subscription emails, and admin session cookies. This could allow an attacker to access the admin panel. The vulnerability was reported to the website's security team.
