## AI Summary

Two Factor Authentication (2FA) in Rocket.Chat was vulnerable to bypass when the server was told to use CAS during login. The 2FA Login Handler skipped validation when it found CAS enabled, allowing login to proceed without validation of a second factor. The vulnerability affected versions 4.3.1, 3.18.3, and develop. The issue was fixed in versions 4.7.5, 4.8.2, and 5.0.0.
