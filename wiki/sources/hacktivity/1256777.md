## AI Summary

A stored XSS vulnerability existed in the main page of a GitLab project caused by arbitrary script payload in the group's "Default initial branch name" field. By changing the field, a malicious user could inject arbitrary JavaScript into the main page of a project, which could be triggered by any user who was either at least a developer of the project or an administrator of the GitLab instance. The impact depended on the instance CSP settings, and if not properly set, the attacker could execute arbitrary commands as the victim and/or generate personal access tokens for full account access.
