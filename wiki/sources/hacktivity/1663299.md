## AI Summary

The HackerOne internal backend interface had a SQL injection vulnerability that allowed an attacker to escape the transaction wrapped around the `EXPLAIN ANALYZE` query, leading to arbitrary code execution. The vulnerability was due to the ability to interpolate the `raw_sql` variable. The attacker could inject a payload into the `user_versions` table and use the `reify` method to execute arbitrary ruby code. The impact was the execution of arbitrary ruby code.
