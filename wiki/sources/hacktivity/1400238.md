## AI Summary

A path traversal vulnerability was found in Apache HTTP Server versions 2.4.49 and 2.4.50, which allowed an attacker to map URLs to files outside the directories configured by Alias-like directives. The fix for CVE-2021-41773 in version 2.4.50 was found to be insufficient, potentially allowing for remote code execution if CGI scripts were enabled for the aliased paths. The issue was fixed in version 2.4.51.
