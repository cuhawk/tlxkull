## AI Summary

An improper authorization vulnerability was found on the `/api/as/v1/credentials/` endpoint for the Dev Role User with Limited Engine Access in Elastic App Search. An attacker with this role could access all API keys, including the Private API Key with read/write access to all engines, allowing for privilege escalation. This vulnerability has been resolved.
