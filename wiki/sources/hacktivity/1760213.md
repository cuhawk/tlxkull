## AI Summary

A cache poisoning vulnerability allowed for stored cross-site scripting (XSS) attacks via the "hav" cookie parameter on abritel.fr, leading to account takeover. The server had a protection mechanism that hid double quotes, but not greater than and less than symbols, which allowed the attacker to bypass the web application firewall (WAF). The server also cached the reflected value in the cookie, which led to any user visiting the page getting XSSed. The session cookie was HTTPonly flagged, but the session was located in clear text in a JavaScript variable on the same page. The vulnerability was fixed by not reflecting the "hav" cookie anymore.
