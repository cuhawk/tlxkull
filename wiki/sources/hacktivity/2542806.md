[CVE-2024-32464] ActionText ContentAttachment's can Contain Unsanitized HTML

Instances of ActionText::Attachable::ContentAttachment included within a rich_text_area tag were discovered to potentially contain unsanitized HTML. This vulnerability was assigned the CVE identifier CVE-2024-32464. Versions affected were 7.1.0 and later, while versions prior to 7.1.0 were not affected. The issue was addressed in version 7.1.3.4.
