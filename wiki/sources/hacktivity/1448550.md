## AI Summary

An IDOR vulnerability on developers.mtn.com allowed any user to remove any other user from their team by modifying the request with the target user's ID. This vulnerability also resulted in an information disclosure as user and team names were disclosed in the response from the server. The vulnerability was remediated by implementing proper session management, access control mechanisms, and validation of access to team IDs.
