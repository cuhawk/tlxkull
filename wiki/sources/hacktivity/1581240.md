## AI Summary

An IDOR vulnerability was discovered in the user invite link in Taxjar, which could have allowed an attacker to take over a user's account without any user interaction. The vulnerability was caused by a leaked token in the delete invitation request feature and was resolved by using the invitation ID instead of the token to look up the user’s invite when deleting an invitation. Validation was added to ensure the ID belongs to the user’s organization.
