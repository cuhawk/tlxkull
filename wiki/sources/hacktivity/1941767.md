## AI Summary

The MetaMask Mobile browser was discovered to ignore Content-Security-Policy headers set by websites, allowing potential execution of scripts that should have been blocked. The issue was caused by an error in how the application handled web requests while trying to ensure the MetaMask JavaScript provider was not blocked. The MetaMask engineering team has since upgraded the MetaMask Browser to address this issue and eliminate complexities that could lead to similar problems in the future.
