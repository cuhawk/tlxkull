## AI Summary

The ZenTao integration in GitLab was vulnerable to an XSS attack due to unsanitized ZenTao issue URLs. An attacker could create a project and configure ZenTao as an external issue tracker, then modify the API response to GitLab to include a JavaScript URL. This could lead to full XSS on self-hosted GitLab instances if a victim visited the infected page and clicked on the link. The vulnerability was fixed by filtering JavaScript URLs.
