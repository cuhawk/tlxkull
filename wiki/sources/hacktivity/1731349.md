## AI Summary

Arbitrary javascript could be executed when a victim views a comment on GitLab due to a stored XSS vulnerability via Kroki diagram. This was possible by crafting a `pre` block so that arbitrary attributes can be injected into the resulting `img` tag. The vulnerability was caused by the lang attribute from the parent node being always used even if the css selector matches the child node. The impact of the vulnerability was that arbitrary javascript could be executed when a victim views a comment.
