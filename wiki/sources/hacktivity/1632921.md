## AI Summary

A vulnerability existed in the --inspect option of Node.js due to an insufficient fix of a previous vulnerability. This allowed an attacker-controlled DNS server to bypass DNS rebinding protection by resolving hosts in the .local domain, potentially leading to remote code execution. The vulnerability was caused by allowing the use of the 0.0.0.0 IP address, which is a reserved address range, and could be exploited by an attacker with access to a compromised DNS server or the ability to spoof its responses.
