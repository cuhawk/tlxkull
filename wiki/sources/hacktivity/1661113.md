## AI Summary

An IDOR vulnerability was discovered that allowed an attacker to modify the links of any user on Reddit. By replicating a request and replacing it with their own authentication headers, an attacker could obtain the links of any user profile with the "id" of each link. The attacker could then modify the links by putting in the request body, in the "id" parameter, the previously saved id, and changing the name and link. The impact of this vulnerability is that an attacker could modify the name and content of any user's social links.
