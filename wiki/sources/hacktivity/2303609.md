## AI Summary

The vulnerability allows cross-site scripting (XSS) when using the `translate` method in Action Controller in Rails versions 7.0 and 7.1. The vulnerability was caused by the implementation of `translate` in Action Controller, which did not properly escape the values passed to it. The vulnerability was not present in Rails version 6.1.
