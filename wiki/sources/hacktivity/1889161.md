## AI Summary

An improper authorization vulnerability existed in all versions of Argo CD starting with v1.8.2, allowing the API to accept certain invalid tokens due to the lack of validation of the audience claim in signed tokens. This could allow an attacker to use a stolen token intended for a different audience to access Argo CD and gain privileges based on the token's groups claim. The vulnerability was patched in versions v2.6.0-rc5, v2.5.8, v2.4.20, and v2.3.14.
