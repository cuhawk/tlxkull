# Android VRP Announces AutoRepro – $1,000 bonus for eligible submissions!

The
[Android & Google Devices Security VRP](https://bughunters.google.com/about/rules/android-friends/6171833274204160/android-and-google-devices-security-reward-program-rules)
is excited to announce that starting today (March 26, 2025), we will be offering
an extra $1,000 bonus reward to researchers who include an AutoRepro test with
their report!

An eligible AutoRepro submission is a VRP report that includes an automated test
that triggers vulnerable conditions to help validate the presence of a reachable
vulnerability in the platform. Submissions are created with the AutoRepro Gradle
Plugin, which combines Tradefed, the Android Gradle Plugin, and utility
libraries specific for creating security tests. An example Android Studio
project is provided as a starting point that includes run configurations and
typical project structure.

To qualify for the $1,000 bonus, researchers must submit their AutoRepro test
with a High or Critical severity report at the time of report submission, and
all tests must be compatible with a Linux host. Tests submitted on Low/Moderate
severity reports or after the time of submission may not qualify for the $1,000
bonus.

For more information on creating and running an AutoRepro test, please visit
[the AutoRepro overview](https://source.android.com/docs/security/test/autorepro).

If you have any questions on AutoRepro tests specifically, please contact
_[android-autorepro@google.com](mailto:android-autorepro@google.com)_.
