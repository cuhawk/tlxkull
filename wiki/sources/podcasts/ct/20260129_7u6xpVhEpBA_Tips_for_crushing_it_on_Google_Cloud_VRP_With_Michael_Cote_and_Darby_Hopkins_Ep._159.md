# Ep 159 -- Tips for Crushing It on Google Cloud VRP

- Date: 2026-01-29
- video_id: 7u6xpVhEpBA
- Speakers: Justin Gardner (JG), guests Michael Cote (Google Cloud VRP), Darby Hopkins (Google Cloud VRP)

## Summary

No extraction -- program-meta only.

Interview with the Google Cloud VRP team walking through the September 2025
rewards table rework: severity buckets S0/S1/S2 (server-side, by attacker
starting privilege), C0/C1 (client-side execution vs other), product tiering
T1/T2/T3A/T3B (T3A = acquisitions, T3B = anything-not-in-table). Discusses
the panel-and-DJ process (two weekly panels, ~15 reports per session, ~four
minutes each, requires unanimous consensus, "panel shopping" routes a report
that doesn't fit Cloud's table over to Abuse/OSS/VRP panels solely to maximize
researcher payout). Covers downgrade reasons (prior access, user interaction
beyond normal product use, exploitability/likelihood, uncommon configuration)
and the 1.2x report-quality bonus across six rubric dimensions (effectively
described, clear impact, attack preconditions, etc.). No exploit patterns,
payloads, CVEs, or novel techniques discussed -- pure program-process content.
